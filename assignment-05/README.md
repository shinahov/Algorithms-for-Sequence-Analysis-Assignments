\# Assignment 05



This folder contains my solution for the programming task about global alignment and backtracing.



The task is to compute the edit distance between two strings using dynamic programming and then reconstruct the alignment.



input:



\- an input file with two strings

\- a band parameter k



reports:



non-banded edit distance

non-banded alignment

banded edit distance

banded alignment



If the length difference of the two strings is greater than k, the program reports that no banded alignment is available.



\## Run



./program input.txt 2
