\# Assignment 03



This folder contains my solution for the programming task about Ukkonen’s suffix tree construction.



The task is to implement a SuffixTree class and construct the suffix tree for an input sequence.



\## Task



The program should support the main suffix tree operations:



\- create new nodes

\- add suffix links

\- move down in the tree

\- use suffix links



The program also outputs the intermediate suffix tree after each phase in DOT format.



Run the program with : python Ukkonen.py TAATA$ 
The dot files will be in the folder Dot
