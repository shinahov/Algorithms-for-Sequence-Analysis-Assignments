\# Assignment 04



This folder contains my solution for the programming task about ±1RMQ.



The task is to preprocess an array with differences only -1 or +1, so that RMQ queries can be answered in constant time.



\## Task



The program takes:



\- an input file with the array

\- index i

\- index j



The program reports the minimum value in the range `\[i, j]` and the smallest index where this minimum occurs.



The program also reports the Sparse Table and the Array P used during preprocessing.

```bash

./program input.txt 2 7
